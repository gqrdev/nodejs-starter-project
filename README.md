# Node Starter Project

This is a basic Node.js starter project using TypeScript and Pino for logging. It includes a simple HTTP server that responds with "Hello, World!" and logs server activity.

## Features
- TypeScript support
- Pino logging
- Simple HTTP server

## Usage
1. Install dependencies: `pnpm install`
2. Start the server: `pnpm start`
3. Open your browser and navigate to `http://127.0.0.1:3000`

## Development
- Run the server in development mode with: `pnpm dev`
- Lint the project with: `pnpm lint`
- Format the project with: `pnpm format`
- Run type checking with: `pnpm typecheck`
